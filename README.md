# 今天做什么

按**真实课表**（教务处导出）+ **教学大纲**，算出今天该做哪几件事，每件都给一句理由。

- 不是课表工具：课表只当输入，输出是「今天先做这 3 件」。
- 不用 AI、不联网、没有后端：所有结论都是「开学日 + 课表 + 大纲」推出来的纯函数结果，离线可用、每次算出来都一样、能看懂为什么。（唯一例外是**可选**的「拍照加作业」，见下文，不填 Key 就完全不联网。）
- 数据只存在你自己手机的 localStorage 里，不注册、不上传。

---

## 两条识别通道，互不打扰

| 通道 | 靠什么 | 要不要 Key / 联网 |
| --- | --- | --- |
| **打字加作业** | 纯本地规则（`parse.js` 的 `parseText`） | 不用 Key，不联网，日期由本地算 |
| **拍照 / 截图** | 智谱 GLM-4V（`today.key.v1` 只存在这台手机） | 要 Key，要联网 |

文字这条路故意不接模型：模型算日期不可靠（实测把「72 小时后」算成一个月后），而本地规则对「N 小时后 / 周五前 / 三天内」是确定性计算，预览里看到什么，入库就是什么。
拍照这条路没有本地文本可依，只能交给模型认字，认完仍然要你在确认卡上核一遍再入库。
## 发版时必须同时升三处（血泪）

1. `index.html` 里四个 `<script src="xxx.js?v=N">` 的 N；
2. `app.js` 里 `navigator.serviceWorker.register('sw.js?v=N')` 和页脚可见的 `BUILD` 字符串；
3. `sw.js` 里的 `CACHE = 'today-vN'`。

只改文件不改 `?v=` 的话，GitHub Pages 的 CDN 会继续把旧 JS 按同一个缓存键返回，手机上看起来「改了等于没改」——这一版就是这么踩到的。页脚那行 `v12 · 2026-10-19` 就是用来核对手机上到底跑的哪一版。
## 三个页签

| 页签 | 作用 |
| --- | --- |
| **今日** | 今天有哪几门课（第几节、在哪）→ 打字 / 拍照加作业 → **作业台账**（没做完的作业全列，按截止时间从早到晚）→ **今天要做**（每门课一条「课前预习」+ 一条「课后复习」，外加每天一条英语）→ **没做完的**（昨天/前天没勾的，留 3 天）→ 下一次课在哪 |
| **进度** | 每门课「课表已上几次 / 大纲共几次 / 现在该讲到哪一章」，外加未来 7 天的课 |
| **设置** | 开学日、智能识别的 Key 与模型、**作业（只列没交的，做完的隐藏但保留）**、导出/导入 JSON、直接改大纲、恢复默认 |

点任意一条任务不会直接划掉：它先变成浅红底，下面冒出「确定做了 / 取消」两个按钮，点「确定」才真正记下（省得手滑把事划没了）。确认后那条从清单里消失，小节标题累加「已勾 N 件」。作业台账里的每一行也是这套确认流程。

**没做完的**：当天生成的预习/复习没勾就一直在——昨天、前天的还在，**第 4 天自动消失**（勾掉就立刻不见）。每条会标「10月17日 周六 留下的」「还剩 2 天」，免得你忘了是哪天的。

**能认的时间写法**：具体日期（10/28、10月28日）、星期（下周三、周五）、相对天数（明天、3 天后、一周后、半个月后），以及**相对小时/倒计时**（70 小时后、剩 2 小时、40 分钟内、作业平台截图里那种「剩余414小时26分钟」）——都按**手机当前时间**往后加，所以「c语言作业70个小时后截止」会算成 10 月 22 日 19:37 这种。

**作业台账**：拍照/打字/手动加进来的作业，全部没做完的都在「作业」这一栏列出来，按截止时间从早到晚排——最上面是逾期（红「逾期 N 天」），然后今天到期的会直接写清还剩多久（**「还剩 3 小时」「还剩 40 分钟」**，过了点显示「今天 23:00 已过」），再往后是「明天到期」「还有 N 天」。同时出现在「今天先做这几件」里的那几条，会多一个「也在今日清单」的小标记，免得看着像重复。

## 打字 / 拍照加作业

老师口头布置作业、群里冒一条通知，两条路都能进作业表：

**① 打字（不要 Key、不联网）**：今日页点「✍ 打字加作业」→ 一行写一条，边写边认（「3 小时后」「今晚 8 点」「剩 2 小时」这类也能算成具体几点）：

```text
高数习题 4.1 下周三交
英语作文周五前交
大物实验报告 三天内
```

输入框下面会实时列出它认到的：科目、要做的事、截止日期、预计分钟。认对了点「认一下」进确认卡，认错了接着改字就行。

**② 拍照 / 截图（可选功能，要 Key）**：拍一张黑板、或者截一张群聊，让它先认出来：

1. 设置 → 「智能识别」→ 填智谱 API Key（<https://open.bigmodel.cn> 控制台里的那一串）→ **保存** → **测试连接**。填的时候可以点旁边的「粘贴」按钮，也可以长按输入框粘贴；保存后标题上会显示「已填 Key（尾号 xxxx）」和存了几位，方便确认没粘漏。
2. 今日页点「📷 拍照 / 截图」→ 手机直接调相机或相册。
3. 弹出一张**确认卡**：科目、要做的事、截止日期、预计分钟——哪一项不对就改哪一项，然后「加入作业表」。
4. **一张图里有多条作业也没关系**：几行通知、群里连着发的几条，都会一条一张小卡列出来（最多 8 条），多的点 ✕ 删掉、漏的手动补一行，最后一次全加进去。
5. 万一模型这次没给准话（只说了句废话、或者答非所问），页面也不给你一个「不知道你要干什么」的死胡同：它会**把图里认到的文字按行摊成草稿卡**，你改个标题、确认下日期就能用。
6. 加进去的作业只有**到期或逾期**那天才会挤进今日清单，不会天天占位。

几个刻意的设计：

- **不直接写库**。模型只负责「把图变成一段结构化的字」，写不写由你点「加入作业表」决定；识别错了你改两个字就行，不用事后去库里删脏数据。
- **宁可多列，不可整个丢掉**。提示词里明确要求「一条一个对象、别合并、别只挑第一条」；解析层也做兜底：就算模型给的 JSON 结构不对、或者答「没有任务」，只要图里有字，就摊成草稿让你改，而不是报「识别失败」。
- **不瞎猜日期**。图里没写截止日期，它默认「明天」，并在卡上标黄告诉你；认不准的科目会落在「其他」，不会硬塞给某门课。
- **先压缩再上传**。照片在本地压到长边 1600px 再发，省流量；压缩时顺手丢掉 EXIF（也就是照片里的拍摄地点）。
- **Key 只存在这台手机上**，不进页面状态、不进导出的 JSON；没填 Key 时点按钮只会提示你去填，**不会向任何地方发东西**。不想用可以整块无视，主体功能完全不依赖它。

用的是智谱 GLM-4V（默认 `glm-4v-flash`，便宜；认不准时在设置里换成 `glm-4v-plus`）。走的是浏览器直连，所以只支持允许跨域的服务商——智谱的和 OpenAI 的都行；百炼、ARK、混元不行（它们不返回跨域头）。

## 它到底怎么算的

```
开学日 + 课表(星期/节次/周次)  → 这门课今天有没有课、第几节
今天有课                     → 课前预习一条 + 课后复习一条
每天                         → 英语一条（当天本身有英语课时，用它的预习/复习顶上，不重复）
作业                         → 到期或逾期才进今日清单，另有完整作业台账
```

今日清单只有这 4 种，顺序也是死的：英语 → 按上课节次，每门课「预习、复习」。

| 类型 | 什么时候出现 |
| --- | --- |
| 英语 | 每天都有一条：背单词 + 读一段 |
| 课前预习 | 今天这门课要上，课前扫一遍上次讲的、翻一眼今天要讲的地方 |
| 课后复习 | 今天这门课上完，当天趁热过一遍 |
| 作业 | 截止日到了或过了还没勾 |

**故意不做的事**：不写「第几章第几节」、不估「约 40 分钟」、不算积压、不排优先级。一章一章算得越准，你越容易被满屏条目劝退；现在就是「今天这几门课，课前看一眼、课后过一遍」，加上一份跑不掉的作业台账。

## 数据与隐私

- 状态存在浏览器 `localStorage` 的 `today.state.v1` 里，换设备用「设置 → 导出 JSON / 导入 JSON」。
- **清浏览器数据会丢**，重要内容顺手导一份。
- 智谱 API Key 存在**另一个**键（`today.key.v1`）里，不进 `state`、不进导出的 JSON、不随「恢复课表默认」被清掉；清浏览器数据才会丢。如果浏览器禁用本地存储（无痕/隐私模式、部分 App 内置浏览器），设置页会直接标红提醒「只能这次有效」，此时 Key 只留在内存里，关掉页面就得重填——遇到这种情况请用手机自带浏览器（Safari / Chrome）打开。
- 只有你点「拍照 / 选截图加作业」并选好图之后，才会把**压缩后的那张图**发给智谱；不点就不发。图片在本地压到长边 1600px 并重编码，EXIF（含拍摄地点）不会跟过去。
- `seed.js` 里已经去掉了姓名和学号；仍包含课程名、教室、任课教师（为了在手机上能查「今天在哪上课」）。如果要公开部署又在意这些，把 `seed.js` 里的 `place` / `teacher` 改成 `实验楼 301` / `某老师` 即可，不影响任何计算。
- 页面里没有任何统计、埋点、第三方请求。

## 改大纲（唯一需要你维护的输入）

设置 → 高级：直接改教学大纲（JSON）。结构：

```json
{ "id": "c-lang", "name": "程序设计(C语言)",
  "outline": [ { "id": "ch1", "title": "第1章 引论", "sessions": 2 } ] }
```

`sessions` = 这门课讲这一章要几次课。各章 session 之和最好等于这门课全学期的上课次数（比如 C 语言 32 次），页面会用它判断「大纲讲完没有」。

## 已知限制（说清楚，不装）

1. **开学日是估的**：`2026-09-07`，等校历出来核对一下。
2. **大纲是按常见教材顺序估的**：课表 PDF 只有时间地点，没有教学进度。实际的章序/次数请你照着老师发的进度改一次，之后基本不用再动。
3. **作业要手动加**：没有对接超星/雨课堂，只有「到期或逾期」的作业才会挤进今日清单。
4. **勾选 id 带日期**：今天勾的是「今天的预习/复习」，跨天不继承——第二天重新给你排一条，本来就是这个用法。
5. **拍照识别会认错**：模型只负责把图变成字，科目认不准会落到「其他」、日期没写就默认明天并标黄提醒，进库前务必扫一眼确认卡。
6. 没有账号系统，换手机靠导出/导入。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 外壳 + 全部 CSS（纸墨风、深浅色、移动端优先） |
| `app.js` | 渲染三个页签、勾选、导入导出、Service Worker 注册 |
| `rules.js` | 纯函数规则层：日期推算、课次定位、今日清单、作业台账、进度统计（Node 与浏览器共用） |
| `parse.js` | 纯函数解析层：把识别出来的文字变成「科目 / 要做的事 / 截止日 / 预计分钟」（Node 与浏览器共用） |
| `seed.js` | 真实课表（13 门课）+ 每门课的大纲（可改）+ 开学日 |
| `test-rules.js` / `test-seed.js` / `test-parse.js` | 零依赖单测 |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | PWA：离线缓存、加到主屏 |

网址参数：`?d=2026-10-15` 看指定日期，`#progress` / `#settings` 直接开到某个页签。
