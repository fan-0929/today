# 今天做什么

按**真实课表**（教务处导出）+ **教学大纲**，算出今天该做哪几件事，每件都给一句理由。

- 不是课表工具：课表只当输入，输出是「今天先做这 3 件」。
- 不用 AI、不联网、没有后端：所有结论都是「开学日 + 课表 + 大纲」推出来的纯函数结果，离线可用、每次算出来都一样、能看懂为什么。（唯一例外是**可选**的「拍照加作业」，见下文，不填 Key 就完全不联网。）
- 数据只存在你自己手机的 localStorage 里，不注册、不上传。

---

## 三个页签

| 页签 | 作用 |
| --- | --- |
| **今日** | 今天有哪几门课（第几节、在哪）→ 今日必做 ≤3 件（带理由、估算时长）→ 剩下的按课程分组 → 积压复习（默认折叠）→ 下一次课讲什么 |
| **进度** | 每门课「应到几次 / 已勾几次 / 落后几次 / 现在该讲到哪一章」，外加未来 7 天的 15 次课 |
| **设置** | 开学日、智能识别的 Key 与模型、作业（到期才进清单）、复习起点、导出/导入 JSON、直接改大纲、恢复默认 |

点任意一条任务不会直接划掉：它先变成浅红底，下面冒出「确定做了 / 取消」两个按钮，点「确定」才真正记下（省得手滑把事划没了）。确认后那条从清单里消失，小节标题累加「已勾 N 件」。

## 拍照 / 截图加作业（可选功能）

老师口头布置的作业，拍一张黑板、或者截一张群聊，让它先认出来：

1. 设置 → 「智能识别」→ 填智谱 API Key（<https://open.bigmodel.cn> 控制台里的那一串）→ **测试连接**。
2. 今日页点「📷 拍照 / 选截图加作业」→ 手机直接调相机或相册。
3. 弹出一张**确认卡**：科目、要做的事、截止日期、预计分钟——哪一项不对就改哪一项，然后「加入作业表」。
4. 加进去的作业只有**到期或逾期**那天才会挤进今日清单，不会天天占位。

几个刻意的设计：

- **不直接写库**。模型只负责「把图变成一段结构化的字」，写不写由你点「加入作业表」决定；识别错了你改两个字就行，不用事后去库里删脏数据。
- **不瞎猜日期**。图里没写截止日期，它默认「明天」，并在卡上标黄告诉你；认不准的科目会落在「其他」，不会硬塞给某门课。
- **先压缩再上传**。照片在本地压到长边 1600px 再发，省流量；压缩时顺手丢掉 EXIF（也就是照片里的拍摄地点）。
- **Key 只存在这台手机上**，不进页面状态、不进导出的 JSON；没填 Key 时点按钮只会提示你去填，**不会向任何地方发东西**。不想用可以整块无视，主体功能完全不依赖它。

用的是智谱 GLM-4V（默认 `glm-4v-flash`，便宜；认不准时在设置里换成 `glm-4v-plus`）。走的是浏览器直连，所以只支持允许跨域的服务商——智谱的和 OpenAI 的都行；百炼、ARK、混元不行（它们不返回跨域头）。

## 第一次用，先做两件事

1. **核对开学日**：设置 → 「第 1 周的周一」。课表 PDF 里没写开学日，页面暂按 `2026-09-07` 推算（= 第 7 周）。如果顶部显示的「第 N 周」和你实际的不一样，把这里改成教务处校历上开学第一周的周一，周次、该讲到第几章、下一次课会跟着全部重算。
2. **点一次「从今天开始记」**：课表 1–16 周每周都有课，第一次打开时，前面几周没勾过的课后复习会全被算成积压（11 件）。点这个按钮把「今天」当起点，之前的都不再催；之后每天正常勾就行。想恢复历史，设置里还能清除。

## 它到底怎么算的

```
开学日 + 课表(星期/节次/周次)      → 这门课哪几天有课、今天是第几次课
第 k 次课 + 大纲(每章 sessions)     → 今天讲到第几章第几次 → 预习哪一节、课后复习哪一节
课表已上过 + 你勾过的课后复习       → 欠了几节 → 顺延/逾期
```

任务只有 7 种，排序规则写死在 `rules.js` 里：

| 类型 | 什么时候出现 | 优先级 |
| --- | --- | --- |
| 逾期作业 | 截止日已过还没勾 | 100 |
| 逾期复习 | 连欠 ≥2 节，或最老一节拖了 >7 天（最多往回翻 21 天 / 4 节） | 90 |
| 今天截止的作业 | 设了截止日且就是今天 | 80 |
| 课后当天 | 今天这门课刚讲完 | 60 |
| 顺延补做 | 上次课的复习还欠着，但没到「逾期」 | 40 |
| 课前预习 | 今天有课，先扫一遍要讲的那一节 | 30 |
| 总复习 | 大纲讲完了，改做综合题 | 20 |
| 提前量 | 今天没课也没积压，别让页面空着 | 10 |

## 数据与隐私

- 状态存在浏览器 `localStorage` 的 `today.state.v1` 里，换设备用「设置 → 导出 JSON / 导入 JSON」。
- **清浏览器数据会丢**，重要内容顺手导一份。
- 智谱 API Key 存在**另一个**键（`today.api.v1`）里，不进 `state`、不进导出的 JSON、不随「恢复课表默认」被清掉；清浏览器数据才会丢。
- 只有你点「拍照 / 选截图加作业」并选好图之后，才会把**压缩后的那张图**发给智谱；不点就不发。图片在本地压到长边 1600px 并重编码，EXIF（含拍摄地点）不会跟过去。
- `seed.js` 里已经去掉了姓名和学号；仍包含课程名、教室、任课教师（为了在手机上能查「今天在哪上课」）。如果要公开部署又在意这些，把 `seed.js` 里的 `place` / `teacher` 改成 `实验楼 301` / `某老师` 即可，不影响任何计算。
- 页面里没有任何统计、埋点、第三方请求。

## 改大纲（唯一需要你维护的输入）

设置 → 高级：直接改教学大纲（JSON）。结构：

```json
{ "id": "c-lang", "name": "程序设计(C语言)",
  "outline": [ { "id": "ch1", "title": "第1章 引论", "sessions": 2 } ] }
```

`sessions` = 这门课讲这一章要几次课。各章 session 之和最好等于这门课全学期的上课次数（比如 C 语言 32 次），页面会用它判断「大纲讲完没有」。

## 已知限制（说清楚，不装）

1. **开学日是估的**：`2026-09-07`，等校历出来核对一下。
2. **大纲是按常见教材顺序估的**：课表 PDF 只有时间地点，没有教学进度。实际的章序/次数请你照着老师发的进度改一次，之后基本不用再动。
3. **作业要手动加**：没有对接超星/雨课堂，只有「到期或逾期」的作业才会挤进今日清单。
4. **勾选 id 带日期**：今天勾的是「今天的课后复习」，跨天不会自动继承；没勾的会被明天的顺延逻辑接住，这正是它的用意。
5. **拍照识别会认错**：模型只负责把图变成字，科目认不准会落到「其他」、日期没写就默认明天并标黄提醒，进库前务必扫一眼确认卡。
6. 没有账号系统，换手机靠导出/导入。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 外壳 + 全部 CSS（纸墨风、深浅色、移动端优先） |
| `app.js` | 渲染三个页签、勾选、导入导出、Service Worker 注册 |
| `rules.js` | 纯函数规则层：日期推算、课次定位、任务生成、进度统计（Node 与浏览器共用） |
| `parse.js` | 纯函数解析层：把识别出来的文字变成「科目 / 要做的事 / 截止日 / 预计分钟」（Node 与浏览器共用） |
| `seed.js` | 真实课表（13 门课）+ 每门课的大纲（可改）+ 开学日 |
| `test-rules.js` / `test-seed.js` / `test-parse.js` | 零依赖单测 |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | PWA：离线缓存、加到主屏 |

网址参数：`?d=2026-10-15` 看指定日期，`#progress` / `#settings` 直接开到某个页签。
